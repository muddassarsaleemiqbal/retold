# Menus and shortcuts

The application menu holds search, open, new video, refresh, appearance and quit. A **Go** menu
lists every destination, bound to ⌘1–⌘8 (Ctrl on other platforms): Home, Videos, Series,
Activity, Providers, Budget, Settings, Help. Shortcut and menu navigation obey the same guards as
the navigation rail: they do nothing while work is in flight, a control is pending or setup has
unsaved input. The native shell journey presses ⌘3 and ⌘1 and asserts Series and Home open.
